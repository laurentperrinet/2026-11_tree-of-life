CHECKS AFTER A DEPLOYMENT

  2. curl -s https://tree-of-life.laurent-perrinet.workers.dev/api/state
     returns JSON whose meshSignature matches js/terrain.js meshSignature().
     (The light form, ?includeTerrain=0, returns the same metadata without the
     elevation payload.)

     a number of seconds next to the sync icon in the status bar.
  4. ?admin > Sign in with GitHub works and shows the lock and login.
  5. Optional, owner only: Reset Terrain increments the shared version.
