Simulation status

👥 Collaborators: distinct browser IDs seen by the Worker since it began counting them; in parentheses, those that synchronized within the last two synchronization intervals (about ten minutes), i.e. currently online.

🔄 Last sync: wall-clock seconds since this browser last synchronized successfully.

⌛ Next sync: wall-clock seconds until the next scheduled attempt; retry delays increase after errors. “--” appears while syncing or when no attempt is scheduled.

🔀 Next merge: wall-clock seconds until the Worker closes its collection window and averages the pending contributions, as reported at the last sync. 0 means the merge will be applied at the next request from any browser; this browser receives the merged terrain at its next sync. “--” means no contribution is pending. The number in parentheses counts the browsers whose contributions are waiting to be averaged.

🤝 Last merge: number of browsers whose elevation changes were averaged into the shared terrain at the Worker's last merge, then how long ago it happened. ✓ means this browser's contribution was among them. Several browsers mean the terrain combines different collaborators' work.

🕰️ Simulation time: cumulative simulated seconds in this browser, saved locally every five seconds and summed across its open tabs. It is not shared between browsers and starts counting from this feature's introduction. Clearing browser storage erases it.

⏱️ Mean transit time: average simulated time from the rim to the sink over the last 100 completed trips. Evaporated parcels are excluded.

💧 Particle flow: water parcels reaching the sink per simulated second over the last 60 simulated seconds, or since startup if less. Evaporated parcels are excluded; water and sediment are recycled.

“sim s” denotes simulation seconds, not wall-clock seconds.

The Worker averages accepted elevation changes per browser and vertex. Contributions based on an older terrain version are discarded. Water, sediment, particles, vegetation and microorganisms remain local to each browser.

The adaptive interval is at least five minutes and targets 80,000 synchronization-related requests per day; it is not a hard request limit. The next sync may occur later if the browser suspends this tab.

View or D changes the display mode. 🔒 identifies a signed-in GitHub account. The GitHub link opens the source code.
